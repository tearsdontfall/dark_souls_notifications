# AI collaboration

This project uses OpenAI Codex as an AI development assistant. The repository owner directs the work and decides which changes to accept.

## Attribution

Commits containing work produced with Codex should include this trailer, separated from the commit message by a blank line:

```text
Co-authored-by: Codex <codex@openai.com>
```

Pull requests prepared with Codex should disclose its assistance in the description and summarize the changes, validation performed, and any remaining limitations. The pull request author is the GitHub account that opens it; commit co-authorship is recorded separately.

Attribution describes actual assistance. It does not imply that OpenAI reviewed or endorsed the project.
